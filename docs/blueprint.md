# **App Name**: StyleFind AI

## Core Features:

- Reverse Image Outfit Search: Analyze user-uploaded images of outfits and identify individual clothing items. If items can be thriftable throw in recs from thrifting stores like depop as well.
- Item Identification & Links: Locate and provide direct purchase links for each identified clothing item, connecting users to retailers.
- Descriptive Shopping Tool: Generates shopping recommendations based on descriptive prompts using a Large Language Model to suggest items aligned with user's style preferences.
- Curated Outfit Display: Showcasing the outfit breakdown with clear images and item descriptions. It uses a UI which displays images and uses clear text
- Shopping Recommendation Feed: Display recommendations in a way which promotes interaction and ease of use
- Favorite Items: Allow users to save favorite clothing items and outfits for later viewing and purchase.

## Style Guidelines:

- Primary color: Deep Indigo (#FAEDCB) to convey a sense of sophistication and style.
- Background color: Light Lavender (#C9E4DE), a desaturated version of indigo, provides a soft backdrop.
- Accent color: Dusty Rose (#C6DEF1), an analogous color, draws attention to interactive elements.
- Font pairing: 'Belleza' (sans-serif) for headlines, 'Alegreya' (serif) for body text to achieve balance elegance.
- Use simple, modern icons to represent categories, search functions, and user profile elements.
- Implement a grid-based layout for consistent item presentation.
- Incorporate subtle animations for item loading and transitions between pages, providing a seamless user experience.
