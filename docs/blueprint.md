# **App Name**: Outfit Finder

## Core Features:

- Image Upload: Allow users to upload images of outfits.
- Outfit Segmentation: Use AI to segment the outfit image into individual clothing items.
- Item Matching: Find visually similar items from available online retailers, using an AI tool that considers the current style profile.
- Link Display: Display the matching items with direct links to purchase.
- Style Preference Updates: Automatically update the user's style preferences based on the analyzed outfits. Store the style profile in the user's local storage
- Preference Display: The users preferences as determined by the AI will be displayed on the user's profile.
- No Account Needed: Since the preference profiles will be saved in local storage, no user account is needed for a more streamlined MVP
- Style Identification: Identify the style of the outfit.
- Piece Recommendation: Recommend additional pieces based on the identified style.

## Style Guidelines:

- Primary color: Indigo (#4B0082), a deep, stylish color suggestive of fashion and luxury.
- Background color: Light lavender (#E6E6FA), a soft, desaturated shade of indigo that provides a gentle backdrop.
- Accent color: Violet (#8F00FF), a vibrant analogous color to indigo that draws attention without clashing.
- Body and headline font: 'Belleza', a humanist sans-serif font with personality aligned to fashion, art, and design
- Use minimalist icons to represent different clothing categories and style preferences.
- Clean and modern layout with a focus on image display and easy navigation.
- Smooth transitions and subtle animations on image loading and item matching.
